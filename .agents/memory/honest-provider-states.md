---
name: Honest provider states
description: Product rule for unavailable AI models, integrations, billing, and other capability dependencies.
---

Unavailable providers must appear as explicit capability states with useful preview behavior, never as fake successful execution.

**Why:** The platform is intended to grow into a trusted international AI company; claiming that a model, integration, citation, or payment action worked when it did not would undermine the core problem-to-outcome promise.

**How to apply:** When a provider is not configured, keep the interface and contract intact, label the capability honestly, and provide the next safe step or preview path without collecting raw credentials in chat.
